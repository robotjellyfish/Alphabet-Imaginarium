# Alphabet-Imaginarium
<https://robotjellyfish.github.io/Alphabet-Imaginarium/>
## TRANSFORM ⴕ𝛠✘ᡶ INTO A 🄳𝕚Ⓖ𔕺𔕛𝐚𝙻 🅁𝗮𝐍🅢𝕠𝙢 🄽Ⓞ𝘁Ꭼ
This tool is a Unicode glyph scrambler that replaces each typed character with a visually similar Unicode character. Glyphs are randomly selected from a predefined glossary of various Unicode blocks and languages that have visual similarity to Latin alphabet letters

### ⚠ PLEASE READ BEFORE COPYING!
<i>Generated text is for decorative use only—and should not be used as a substitute for readable text. Visually similar glyphs are different Unicode characters; therefore, software and screen readers can treat them differently, pronounce them unpredictably, or fail to display them at all. Keep names, instructions, and accessibility-critical text in ordinary readable characters.</i>
