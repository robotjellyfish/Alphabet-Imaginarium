For proper rendering of characters, environment MUST support UTF-8 text encoding and utilize comprehensive font families (such as Noto Sans or system UI fonts) capable of displaying extended Unicode blocks.
This tool generates decorative text that is not a substitute for readable text. Visually similar glyphs are different Unicode characters so software and screen readers may treat them differently, will pronounce them unpredictably, and can fail to display them entirely. Ensure names, instructions, and accessibility-critical text is in ordinary readable characters.
